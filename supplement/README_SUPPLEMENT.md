# Supplementary Material README

This supplementary package supports the manuscript "A Synthetic Stress-Testing Protocol for Ranked Matchmaking Systems".

## Contents

- `src/`: simulation source code used for synthetic ranked-matchmaking experiments.
- `scripts/`: reproducibility, aggregation, reference-check, and figure-generation scripts.
- `config/`: YAML configuration files for simulation profiles and performance settings.
- `results_csv/`: generated CSV summaries and raw companion diagnostic tables.
- `validation/`: questionnaire materials, anonymized pilot annotation files, field mappings, and analysis outputs.
- `validation_release_zh/`: Chinese annotation release materials for reproducibility of the pilot questionnaire protocol.
- `figures/`: submission figures generated from code or editable vector sources.
- `tables/`: editable LaTeX table sources.
- `supplement/`: supplementary annotation and Ruikin diagnostic-layer appendices.

## Reproducibility Notes

The main manuscript reports synthetic simulation results. The auxiliary questionnaire data consist of anonymous ratings of synthetic session summaries and do not contain real player logs or sensitive personal information. All submission figures are generated from code or editable vector sources; no generative AI artwork is used for the figures.

The synthetic simulation data, source code, configuration files, generated CSV summaries, figure-generation scripts, and supplementary materials are available in a public GitHub repository: https://github.com/mds666886/ranked-matchmaking-stress-test. Supplementary material is also provided with this submission.
