# English Codebook for Chinese Annotation Fields

The Chinese annotation form is mapped to English analysis fields in `annotation_field_mapping_zh_en.csv`.

All 1--7 rating items use anchors: 1 = no meaningful issue, 4 = some issue but not severe, 7 = very salient issue requiring system attention.

Real completed human files must set `data_source=human_annotation_real`. Synthetic annotator files must set `data_source=synthetic_annotator_model`. Blank protocol files use `annotation_protocol_only`.
