# 中文标注字段解释

所有 1--7 分题目使用同一锚点：1 = 基本没有问题；4 = 有一定问题，但不严重；7 = 问题非常明显，值得系统重点关注。

- 感知不公平_1_7：你认为该片段中的匹配经历有多不公平。
- 挫败风险_1_7：你认为该片段可能带来挫败感的风险有多高。它不是实际心理测量。
- 段位错位显著性_1_7：你认为可见段位/进度与隐藏实力估计之间的错位是否明显。
- 系统关注必要性_1_7：你认为系统设计者是否应该关注这类片段。
- 是否可接受_1_7：如果你是该玩家，你是否仍认为这组比赛可以接受；高分代表更可接受。
- 判断置信度_1_7：你对自己判断的确定程度。

请注意：所有 session 都是合成模拟数据，不是真实玩家记录。
