# Ruikin Ethics and Scope Note

Ruikin uses questionnaire responses from real human annotators, but the objects being rated are synthetic session summaries generated by the simulation. The annotation data are not real player logs and do not contain sensitive personal information. The analysis uses only rows marked `human_annotation_real`; synthetic annotator outputs are excluded from Ruikin training and evaluation.

The Ruikin outputs are diagnostic proxies:

- `R_F`: fairness diagnostic;
- `R_A`: affective-strain proxy;
- `R_P`: progression-tension score;
- `R_S`: stickiness-risk proxy;
- `R_T`: risk-transfer score;
- `R_C`: composite diagnostic.

These outputs should not be interpreted as real emotion recognition, real engagement measurement, retention prediction, or churn prediction. Submission should still include a human check of whether the institution or journal requires an ethics exemption statement for anonymous questionnaire judgments over synthetic session summaries.
