# README for Human Annotators

This validation package is designed for a future expert/player annotation study. It has not been completed with real annotators in the current submission package.

Annotators will review short synthetic ranked-session summaries. Each session contains only simulation-derived descriptors, not real player telemetry. Please rate each session independently.

## Rating Questions

Use a 1--7 scale where 1 means very low and 7 means very high.

- Perceived unfairness
- Frustration risk
- Progression-mismatch salience

Also mark whether the session seems acceptable or concerning.

## Important Boundary

The synthetic variables are diagnostic cues. They are not measurements of real satisfaction, churn, or mental state.
